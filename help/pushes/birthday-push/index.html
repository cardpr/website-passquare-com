Birthday push notifications

Automatic birthday pushes are set up with a trigger in your account. Every day the trigger checks dates of birth and sends a message to customers who have a birthday.

Collect the date of birth

For the trigger to work, the customer must have a date of birth. Enable the Date of birth field on the card issuance form, in Issuing cards.

Create a trigger

  1. Go to Triggers and click Create trigger.
  2. In the condition, select Birthday. If needed, set how many days before the birthday to send the message: 0 means on the birthday itself.
  3. In the action, select sending a push message.
  4. Enter the text. You can use variables, for example cardholder_name to insert the cardholder's name. The full list of variables is in Settings → Variables.
  5. Save the trigger and turn it on.

One-off campaign to birthday customers

To send a message manually, create a segment of customers with a birthday and send them a text push. Before a mass send, you can send a personal push to your own card.

Notes

  1. Triggers are available on plans that include a trigger limit. See the number on the Pricing page.
  2. The message is delivered if the cardholder has notifications enabled and an internet connection.
  3. The Apple Wallet format allows only text in a push message.
