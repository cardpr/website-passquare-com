1C integration

The integration module works with the following 1C applications:

  • Retail, editions 2 and 3;
  • Retail. Clothing and footwear store, edition 2;
  • Trade Management, edition 11;
  • Our Company Management, edition 3;
  • Beauty Salon, edition 3;
  • BIT. Medical Center Management, edition 2;
  • Jewelry Trading House, edition 10;
  • Comprehensive Automation, edition 2;
  • ERP Enterprise Management, edition 2;

and others on the 1C platform version 8.3.16 or later.

  • The extension works both in a standalone 1C:Retail 2 infobase (one store) and in a distributed 1C:Retail 2 information system (a chain with several stores).
  • Cloud services are supported (1C:Fresh and others).
  • The integration module can be adapted for other 1C configurations.

To check whether we can connect your setup, please provide:

  • 1C technology platform version (see the About dialog).
  • Configuration name and version (see the About dialog).
  • Infobase mode — file or client/server (see the About dialog).
  • Whether you use a single standalone infobase or a distributed infobase (DIB).
  • Where the infobase is hosted — on your own server or in the cloud, and which cloud provider.
  • Whether you have an external static IP address that can host the 1C integration service publication.
  • Whether you use an Apache or IIS web server.
  • Whether you have a system administrator who also administers 1C.
  • Whether you have a 1C specialist.

This solution is not included in Passquare plans and is billed separately.

Contact Passquare support before you connect.

You can also ask Passquare support about alternative integration options, including other versions and configurations.
