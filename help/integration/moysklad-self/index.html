Self-serve Moysklad integration

To set up the integration, you need a discount or bonus loyalty program configured in Moysklad. If you do not have an active loyalty program yet, in Moysklad go to Settings — Discounts and configure a discount or bonus program. If needed, use the guides or contact Moysklad support: https://support.moysklad.ru/hc/ru.

In Passquare settings, set the starting wallet card number. This number must be greater than the numbers of cards already created in the CRM.

  1. Open your Passquare account and go to Integration.
  1. If a demo period is on, turn it off before you set up the integration.
  1. Click the CRM system field and select Moysklad from the drop-down list.
  1. Leave the Server field empty.
  1. In Login, enter the Moysklad user login in the format `admin@admin`. For the integration to work correctly, use a user with administrator rights.
  1. In Password, enter the Moysklad user password.

7.1. If you use a discount system, in Additional parameters enter:

{ "groups": [ "Moysklad_discount_group_name" ], "programType": "accumulationdiscount" }

This is the group name that will be assigned to new customers.

7.2. If you use a bonus system, in Additional parameters enter:

{ "groups": [ "Moysklad_bonus_group_name" ], "programType": "bonus" }

This is the group name that will be assigned to new customers.

  1. If you use a bonus system, or if the discount amount can change, select Subscribe to hooks.
  1. Click Save, then turn the integration on.
  1. If you already have issued cards in your Passquare account, go to Customers and, in the lower-right corner, click Write to CRM.

Integration details

  • Bonus accrual and redemption, and discounts, are configured and processed in your Moysklad system.
  • With Moysklad, wallet cards support automatic bonus balance updates.
  • Customers can refresh discount information on their card themselves. Discounts are not updated automatically because of Moysklad technical limitations.
  • Moysklad does not support multiple cards — when a wallet card is created, the plastic card is deactivated.
  • After a card is issued, the customer and card usually appear in Moysklad within a few minutes to a few hours. The maximum delay is 24 hours. Timing depends on system load and the update queue.
  • When the bonus balance changes in Moysklad, Passquare and the customer card update within a few minutes to a few hours. Timing depends on system load and the update queue.
