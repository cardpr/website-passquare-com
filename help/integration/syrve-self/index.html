Self-serve Syrve integration

To set up the integration, you need:

  1. A loyalty program configured in Syrve.
  2. Starting wallet card number. It must be greater than the numbers of cards created earlier.
  3. List of loyalty program categories with percentages.
  4. API key from Syrve (permission template: all rights, email: ).

In Passquare settings, set the starting wallet card number. It must be greater than the numbers of cards already created in the CRM. Go to Integration. If a demo period is active, end it.

Click the CRM system field and select Syrve from the drop-down list. In Server, enter `https://api-eu.syrve.live/` In Login, enter the API key from Syrve. Click Check and Save. The Server and Login fields should turn green. In Organization ID, select the organization where the loyalty program is connected. In Program ID, select your loyalty program. Click Save.

Open the Categories tab. Click Add category. In Name, select the category you need from the drop-down list. In Type, select the matching loyalty program type — discount or bonus. In Percent, enter the percentage for that category, for example 5.00.

Add the other categories you use in the same way. Then click Save and turn the integration on.

If you already have issued cards in your Passquare account, go to Customers and, in the lower-right corner, click Write to CRM.

Add a webhook in Syrve

For automatic bonus updates on guest cards, in Syrve go to Settings → Webhook notifications. Select the organization used for the integration. Then click Create.

Name: Passquare (if RFM analysis is not connected)

Single webhook notification URL: `https://core.passquare.com/api/v2/syrve/hook`

Batch webhook notification URL: `https://core.passquare.com/api/v2/syrve/hook?batch`

Name: Passquare-RFM (if RFM analysis is connected)

Single webhook notification URL: `https://core.passquare.com/api/v2/syrve_rfm/hook`

Batch webhook notification URL: `https://core.passquare.com/api/v2/syrve_rfm/hook?batch`

Select these checkboxes:

  • user balance change;
  • guest category change;
  • user card change;
  • user membership change.

Then save the settings.

After you create the hooks, in Syrve go to Settings → Settings and set Default subscription to Passquare.

Integration details

  • Bonus accrual and redemption, and discounts, are configured and processed in your Syrve system.
  • After a card is issued, the guest and card usually appear in Syrve within a few minutes to a few hours. The maximum delay is 24 hours. Timing depends on system load and the update queue.
  • When the bonus balance or discount changes in Syrve, Passquare and the guest card update within a few minutes to a few hours. Timing depends on system load and the update queue.
  • If you plan to change how bonuses are accrued or discounts are granted, tell us so we can update the integration settings. Access to Syrve with rights to Guests and Guest accounts may be required.
  • Do not edit the card number in Syrve. The guest’s bonuses and discounts will not be sent to Passquare or shown on the card. If a guest’s phone number changes, the guest needs to get a new card through Passquare.
