Self-serve Klientiks CRM integration

To set up the integration, you need:

  • A loyalty program configured in Klientiks CRM;
  • Starting wallet card number. It must be greater than the numbers of cards created earlier;
  • API enabled in Klientiks CRM;
  • Company ID;
  • User ID;
  • Authorization token.

In Passquare settings, set the starting wallet card number. This number must be greater than the numbers of cards already created in the CRM.

Open this link: https://klientiks.ru/clientix/admin/eventHandlers

If the link does not open, check that you are signed in to Klientiks CRM in the browser as a user with full rights.

In the window that opens:

  • Click Add event — webhook;
  • In Event, select Customer changed;
  • In Request URL, enter:

https://core.passquare.com/api/v2/klientiks/webhook/PUBLIC_API_KEY?old_phone={{#old_data}}{{phone}}{{/old_data}}&phone={{#new_data}}{{phone}}{{/new_data}}&id={{#new_data}}{{id}}{{/new_data}}&birth_date={{#new_data}}{{birth_date}}{{/new_data}}&loyalty_program_status={{#new_data}}{{loyalty_program_status}}{{/new_data}}&first_name={{#new_data}}{{first_name}}{{/new_data}}&patron_name={{#new_data}}{{patron_name}}{{/new_data}}&second_name={{#new_data}}{{second_name}}{{/new_data}}

where PUBLIC_API_KEY is the Passquare public key.

Open your Passquare account and go to Integration. If a demo period is active, end it.

Click the CRM system field and select Klientiks CRM from the drop-down list. In Server, enter `https://klientiks.ru`; In Login, enter the user ID; In Password, enter the authorization token; In Organization ID, enter the company ID; Click Save, then turn the integration on.

If you already have issued cards in your Passquare account, go to Customers and, in the lower-right corner, click Write to CRM.

Integration details

  • Bonus accrual and redemption, and discounts, are configured and processed in your Klientiks CRM system.
  • After a card is issued, the customer and card usually appear in Klientiks CRM within a few minutes to a few hours. The maximum delay is 24 hours. Timing depends on system load and the update queue.
  • When the bonus balance or discount changes in Klientiks CRM, Passquare and customer cards update within a few minutes to a few hours. Timing depends on system load and the update queue.
  • Cards can be issued both from the Passquare issuance form and from Klientiks CRM. If you want to use only one issuance method, tell Passquare support.
  • If you issue cards from Klientiks CRM, you need an SMS service to send customers the card install link automatically.
