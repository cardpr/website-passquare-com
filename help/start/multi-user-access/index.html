Multi-user access

If the account keeps ending your session and asking you to sign in again, the same login is usually open on more than one device.

One login, one active session

Under the current service rules, only one session can be active for a login. A new sign-in with the same email on another device ends the previous session.

A cash register, a phone, and an admin computer that all use the same email keep ending each other’s sessions. From your side, it looks as if the account signs itself out.

A separate login for each workplace

Each workplace needs its own login. Create separate access in your account: Settings → Access.

Each workplace uses:

  • a unique email address as the login;
  • its own password.

These logins all work in the same account: cards, customers, and settings stay shared. Only the sign-in is separate. The cash register, a phone, and other devices can stay signed in at the same time without ending each other’s sessions.

How to invite a user, and what to do if the invitation email does not arrive, is covered in Add a new user.

If you used to sign in on several devices with one account

Previously, one login could be used on several devices at once. That now causes limits: only the latest session stays active, and the others end.

Create a separate login for each workplace and sign in on each device with its own email and password.
