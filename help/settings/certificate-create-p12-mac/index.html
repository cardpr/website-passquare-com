Get a Pass Type ID certificate (Mac)

Attention: Read this guide in full before you start obtaining a certificate.
  1. Go to https://developer.apple.com and select the Account tab. If you do not have an Apple Developer account yet, create one using these guides: for an individual or for a company.
  2. Enter your Apple ID to sign in to the developer section.
  3. In the Certificates, Identifiers & Profiles menu, select Identifiers.
  4. Go to Identifiers and click the + icon.
  5. Select Pass Type IDs and click Continue.
  6. If a Passquare demo certificate was used, delete the Pass Type ID in your Passquare account before registering a Pass Type ID. Go to Settings › Certificates › Apple Wallet › Set up › Delete Pass Type ID.
  7. In the Description field enter “Passquare”, and in the Identifier field enter pass.com.passquare.account_name (for example: pass.com.passquare.demo), then click Continue.
  8. Click Register. This registers a Pass Type ID. Next, create the certificate itself to manage wallet cards.
  9. Go to Certificates and click the + icon.
  10. Select Pass Type ID Certificate in the Services section.
  11. Click Continue.
  12. In the Enter your Pass certificate Name field enter “Passquare”, in the Pass Type ID field select the identifier you created earlier, and click Continue. Attention: The next steps require a Mac. If you do not have one, use the https://crt.passquare.com/ microservice. The promo code is available in your Passquare account under Settings › Certificates.
  13. On the Mac, open Keychain Access.
  14. In the top-left corner, choose Keychain Access › Certificate Assistant › Request a Certificate From a Certificate Authority.
  15. Enter your email (User Email Address) and name (Common Name) as they appear in the Apple Developer account. Under Request, select Saved to disk, click Continue, and save the file to your computer.
  16. Return to the browser window, click Choose File, upload the file you created, and click Continue.
  17. Click Download.
  18. Return to Keychain Access. In the top-left corner choose File › Import Items and select the certificate file.
  19. Right-click the certificate and choose Export. If you do not see an option to export as *.p12, go to My Certificates and try again.
  20. Name the certificate Certificate.p12 and click Save.
  21. Create a password for the certificate (Latin letters and digits, at least 8 characters) and click OK.
  22. Enter the keychain password and save the certificate.
  23. Upload the certificate in your Passquare account under Settings › Certificates › Apple Wallet › Set up › Upload Pass Type ID certificate *.p12.

After you upload and activate the certificate, you can manage Apple Wallet cards. For the service to work fully, you also need to set up and activate a certificate for Google Wallet cards.
