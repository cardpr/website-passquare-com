Add a custom field

Variables are used to show personalized information on cards, collect customer data when cards are issued, and exchange data between systems.

To add a variable:

  1. Go to Settings, Variables tab.
  2. Click Add variable.
  3. In the dialog that opens, fill in the fields:
  • Name — must be unique. Use Latin letters with no spaces.
  • Default value — fill this in only if the field should have a value by default.
  • Description — add a note about how the new variable will be used. The description is visible only to you; your customers will not see it.

You can add the new variable to a card template field, create a new field on the card issuance form, or use it in an integration as described in the technical documentation.
