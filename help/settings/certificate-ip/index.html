Create an Apple Developer account for an individual

Attention: Read this guide in full before you start creating an account.

An Apple Developer account can be created for a company (legal entity) or for an individual. An account created for a company has no limit on the number of developers who can access it. An account created for an individual gives access to only one developer. An Apple Developer account costs $99 / year.

Registering an account for an individual takes 1–3 days.

Alternative option (since April 2021, Apple recommends this method): Install the Apple Developer app from https://apps.apple.com/app/id640199958?mt=8 on iPhone or iPad. Follow the official guide: https://developer.apple.com/support/app-account/. Note that local taxes may be added to the account fee.

Step 1. Register an Apple ID

To register as a developer (required to issue a certificate):

  1. Go to https://developer.apple.com/programs and sign up. We recommend creating a new Apple ID.
  2. Select the Account tab.
  3. In the sign-in form, click Create yours now.
  4. Fill in the Apple ID form. Enter the first and last name exactly as they appear on the debit card that will be used for payment. When registering, we recommend using the account holder’s details. Important: When working with Apple, always enter accurate information in every form. This helps avoid problems later, speeds up decisions on your case, and makes the process much easier. A single typo in a company name or other key details often means you have to start over.
  5. A confirmation code will be sent to your email.
  6. A confirmation code will be sent to your phone.
  7. Select the checkbox confirming that you have read the license agreement below the text, and accept it (blue Submit button).
  8. Your Apple ID is now created. Go to https://developer.apple.com/programs using the direct link.

Step 2. Enroll as a developer

  1. On https://developer.apple.com/programs click Enroll, select Individual, fill in first and last name, address, and phone number, and accept the license agreement.
  2. Click Start Your Enrollment.
  3. Enter your Apple ID to sign in to the developer section.
  4. Confirm your personal information.
  5. Select the entity type Individual.
  6. Select the agreement checkbox and click Continue.
  7. Complete payment on the card details page. We recommend issuing a prepaid virtual card for the required amount and entering its details.
  8. Within 1–3 days the funds will be charged, and you will receive an email with an activation code to complete registration.

Click the code in the email and click Continue in the window that opens. The Get Started button will then become available. After you click it, you will get access to the Developer Member Center, with the full developer feature set, support, and access to the developer portal.

Step 3. Set up the account

  1. Sign in at https://appleid.apple.com.
  2. Enter your Apple ID credentials.
  3. Upload the certificate to your Passquare account. Go to Settings › Certificates › Apple Wallet › Set up › Upload Pass Type ID certificate *.p12. You can upload the certificate yourself or ask us to do it. If you need us to connect, enter the Apple ID and password in the corresponding fields and contact support.
Attention: An Apple Developer account is billed for 1 year. When the subscription ends, the certificate stops working and you will not be able to issue or maintain cards. Renew the subscription 1 month before it expires. Renewal can take time, so start early.
