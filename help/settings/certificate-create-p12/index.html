Get and renew a Pass Type ID certificate

Attention: Read this guide in full before you start obtaining a certificate.

Apple Wallet card usage is governed by the “Apple Developer Program License Agreement” at https://developer.apple.com/terms/.

  1. Go to https://developer.apple.com and select the Account tab. If you do not have an Apple Developer account yet, create one using these guides: for an individual or for a company.
  2. Enter your Apple ID to sign in to the developer section.
  3. In the Certificates, Identifiers & Profiles menu, select Identifiers.
  4. If you do not yet have a Pass Type ID, go to Identifiers and click the + icon. If you already have a Pass Type ID, skip to step 8 (create the certificate) and use it. To check whether a Pass Type ID exists, change the filter on the right from App IDs to Pass Type ID.
  5. Select Pass Type IDs and click Continue.
  6. In the Description field enter “Passquare”, and in the Identifier field enter pass.com.passquare.account_name (for example: pass.com.passquare.demo), then click Continue.
  7. Click Register. This registers a Pass Type ID. Next, create the certificate itself to manage wallet cards.
  8. Go to Certificates and click the + icon.
  9. Select Pass Type ID Certificate in the Services section.
  10. Click Continue.
  11. In the Enter your Pass certificate Name field enter “Passquare”, in the Pass Type ID field select the identifier you created earlier, and click Continue. Next you need a certificate signing request. You can use the https://crt.passquare.com/ microservice, which works on any operating system.
  12. Open https://crt.passquare.com/ in a new browser tab.
  13. Choose Create an individual CSR request if your Apple Developer account is registered to an individual; choose Create a CSR request for an organization if it is registered to a company.
  14. Enter the promo code (available in your Passquare account under Settings › Certificates), first and last name (for an individual) or organization name (for a company), and the email address used in the Apple Developer account. Then click Create CSR request to download the file to your computer. Create the CSR request on a computer. Downloading this file from a phone is not possible and will cause a “profile error”.
  15. Return to the Apple Developer tab, click Choose File, select the file you downloaded, and click Continue.
  16. Click Download. You will download a certificate in CER format; next you need to convert it to P12.
  17. Return to the https://crt.passquare.com/ tab, choose Create a P12 certificate, enter the promo code and email (the same ones you used when generating the CSR request), and select the certificate file downloaded from Apple Developer.
  18. Click Create certificate. An archive with the P12 certificate and its password will be downloaded to your computer.
  19. Upload the certificate in your Passquare account under Settings › Certificates › Apple Wallet › Set up › Upload Pass Type ID certificate *.p12.

After you upload and activate the certificate, you can manage Apple Wallet cards. For the service to work fully, you also need to set up and activate a certificate for Google Wallet cards.
