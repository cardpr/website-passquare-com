Update the Apple Wallet certificate

  1. Go to https://developer.apple.com and select the Account tab.
  2. Enter your Apple ID to sign in to the developer section.
  3. In the left menu, select Certificates, Identifiers & Profiles.
  4. Go to Certificates and click +.
  5. Select Pass Type ID Certificate in the Services section.
  6. Click Continue.
  7. In the Enter your Pass certificate Name field enter Passquare, in the Pass Type ID field select the identifier pass.com.passquare.account_name, and click Continue.
  8. Go to https://crt.passquare.com.
  9. Choose Create an individual CSR request or Create a CSR request for an organization, depending on your Apple Developer account type.
  10. Enter the promo code you received from Passquare support and fill in the details from the Apple Developer account.
  11. Click Create CSR request. A .pem file will be downloaded to your computer.
  12. Go to Apple Developer, click Choose File, upload the downloaded .pem file, and click Continue.
  13. Click Download in Apple Developer. A .cer file will be downloaded.
  14. On https://crt.passquare.com, refresh the page and choose Create a P12 certificate.
  15. Enter the promo code you received from Passquare support.
  16. Enter the user email from Apple Developer.
  17. Click the empty Certificate .cer field and select the .cer file downloaded from the Apple Developer account.
  18. Click Create certificate. The P12 certificate and its password will be downloaded to your computer as a Zip archive. Extract the files.
  19. In your Passquare account go to Settings, Certificates tab, click Set up, then in the dialog click Replace and confirm deletion.
  20. Upload the new certificate, enter the password from the text file you extracted in step 18, and save the changes.
  21. Go to Card templates, select any template, and click Update all cards at the bottom.
