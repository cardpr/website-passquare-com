Add a new user

You can invite colleagues to your Passquare account so they can work with cards, customers, and settings together with you. To do this, send an invitation to the user's email address.

How to send an invitation

  1. Go to Settings, Access tab.
  2. Click Add.
  3. In the dialog that opens, enter the email address of the user you want to invite.
  4. An email with a link to create an account and join yours will be sent to that address.

The invited person opens the email, follows the link, and completes sign-up. After that they appear in the list on the Access tab and can sign in to the account.

If the invitation email did not arrive

There is no need to wait for the email. The user can sign up for a Passquare account with the same email you entered when sending the invitation, then accept it in the Invitations section.

  1. Go to the sign-up page https://my.passquare.com/#/signup.
  2. Create an account with the same email the invitation was sent to.
  3. After signing in, open the Invitations section and accept the invitation.
