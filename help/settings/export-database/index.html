Export the customer database

Export saves the customer database to a CSV file for a selected period and emails the archive to the user who requested it. The file contains personal data: contact details, card information, balance, bonuses, and discount.

If a CRM is connected to the account, customer data is synced with it. The same data can also be retrieved through the API. Use export when you need a file for a specific period.

Where to find export

Open Settings and go to the Export tab. The file cannot be requested from the Customers page.

How to allow export

The tab has a switch labeled Allow export of the customer database to CSV. While it is off, the Export CSV button is disabled and a new file cannot be requested.

To turn export on:

  1. Click the switch.
  2. Read the warning: the file contains customers’ personal data, you can request it no more than once a day, and only for a period of one month or less.
  3. Check the agreement box and click Enable.

By enabling export you confirm that you do so on a lawful basis and that you are responsible for any later use, storage, and sharing of the exported data.

To stop new exports, turn the same switch off. Requests that were already made stay in the journal.

A user with view-only access cannot turn export on and cannot request a file.

How to request a file

  1. Open Settings → Export.
  2. Make sure export is allowed.
  3. Under the journal, click Export CSV.
  4. Set Start of selection and End of selection.
  5. Fill in the journal details: Your full name, Your job title, Your phone number, and Purpose of the personal data export. All four fields are required. The purpose must be at least 100 characters.
  6. Check the agreement to request personal data and click Export.

Request limits:

  • an export can be started no more than once a day;
  • the interval from the start date to the end date is one month at most;
  • the end date cannot be earlier than the start date;
  • export is unavailable during the demo period.

The file includes customers registered in the account from the start date through the end date, inclusive.

The finished archive arrives within a few hours at the email address you used to sign in. It is a password-protected ZIP archive containing export.csv. The archive name includes the period, for example export_01-09-2026_28-09-2026.zip.

Archive password

Right after the request, a dialog shows the password. Copy it and save it: the password is shown only once. It is not included in the email or in the export journal. The archive will not open without it.

What is in the file

The CSV includes columns for:

  • first name, last name, and middle name;
  • email and phone;
  • the customer’s registration date and IP address;
  • date of birth;
  • card form, template, and modifier;
  • card number and track;
  • balance, bonus, and discount;
  • whether the card is installed on a device;
  • extra customer fields, if they are filled in for the account.

Export journal

Every request is recorded in the journal on the same Export tab. The journal stays available after export is turned off.

The columns appear in this order:

  • Status — “In progress” or “Completed”;
  • Date — the day of the request, without the time;
  • Full name — the name entered with the request;
  • Job title;
  • E-mail — the email of the user who requested the file;
  • Period — the start and end of the selection;
  • Purpose — the export purpose text.

The phone number is stored with the request and is not shown in the journal table.

“In progress” means the file is still being prepared. “Completed” means the request was processed and the email with the archive was sent. If the status stays “In progress” for a long time, contact support.
